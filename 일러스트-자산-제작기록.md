# ImageGen 독립 일러스트 제작 기록

내장 imagegen 도구 사용. 유료 API/CLI를 사용하지 않았습니다. 최종 WebP 자산은 `public/assets/art/` 안에 있습니다. 시트에서 각 그림을 자르고 크기를 맞춰 독립 파일로 저장했으며, 앱은 각 파일을 개별 호출합니다. 기존 한도 문제의 140개 그림도 같은 방식으로 분리했습니다. 원본 시트는 기본 generated_images 위치에 보존합니다.

# 2026-11-15 추가 제작 및 투명 보정

- 내장 ImageGen만 사용. 별도 API 키·유료 API·유료 호스팅을 사용하지 않음.
- 기존 그림을 참조하여 고구마·감자·당근·무·호박·배추·통조림·종이상자의 흰 배경을 제거. 각각 `*-v2.webp`로 독립 저장. 실제 완전 투명 픽셀 비율 47~73% 확인.
- 멜론·수박·자전거·텔레비전은 각각 별도의 생성 요청으로 제작, `melon`, `watermelon`, `bicycle`, `television` v1 자산으로 저장. 요청: 사실적이고 부드러운 교육용 일러스트, 한 물건 전체, 좁은 여백, 글자·숫자 없음, 실제 알파 투명 배경.
- 욕조: 기존 그림을 참조하여 흰색/회색 테두리 번짐을 없애고 은색 수도·다리·물이 보이는 흰 욕조로 개선. `bathtub-v2.webp`.
- 원본 PNG는 Codex generated_images 폴더에 보존. 프로젝트 자산은 WebP 512×512로 포장했으며 코드에서 독립적으로 호출함.
- 물의 양·눈금·바늘·무게 숫자는 생성 이미지에 그리지 않고 검증된 수학 코드로 표시함.
