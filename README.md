# 들이와 무게 탐험대

LNG는 Liter & Gram입니다. 초등학교 3학년 2학기 들이와 무게 학습용 웹앱입니다.

원리 10단계와 응용 7단계에서 풀이 방법에 따라 묶은 유형을 섞어 출제합니다. 응용편 정답은 문항당 2점입니다. 여러 칸이 있는 문제는 모두 맞아야 정답 1회로 처리하고, 틀린 칸에 빨간 색연필 표시를 합니다. 기본 배경은 제공받은 빵집이며 칠판 배경도 선택할 수 있습니다.

## 무료 운영

GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다. Firebase `lng-adventure`의 결제 계정 없는 Spark 프로젝트에서 Authentication과 Realtime Database만 사용합니다. Functions, Cloud Run, 유료 AI API는 사용하지 않습니다. 무료 할당량을 넘으면 기능이 제한될 수 있으며, 결제 계정을 연결하지 않습니다.

```powershell
npm install
npm test
npm run build
npm run preview
```

별도 로그인 화면 없이 문제 화면의 우상단에서 반·번호를 고릅니다. 최초 방문자는 무작위 동물 닉네임을 다시 뽑아 확정하고, 같은 비밀번호 칸에서 개인 비밀번호를 한 번 안내받습니다. 재방문자는 해당 반·번호의 동물 닉네임이 자동 표시되며 비밀번호를 직접 입력합니다. 이후 반·번호·비밀번호 또는 개인 QR로 로그인합니다. 교사는 별도 교사 페이지에서 계정과 QR을 조회하고 한 반 25장을 A4 한 페이지로 출력할 수 있습니다.

초기 계정 기록은 로컬 `.private`에만 보관하며 공개 저장소에 올리지 않습니다. 공개 Firebase 웹 설정은 관리 키가 아닙니다. 학생별 읽기·쓰기 권한은 Firebase 보안 규칙으로 분리합니다. 문제 생성과 채점은 브라우저에서 실행되므로 시험용 부정행위 방지 시스템을 제공하지 않습니다.

수치와 그림은 동일한 정수 mL/g 데이터로 생성합니다. 배경의 계량컵은 장식이며 채점 근거가 아닙니다. 자동 검증은 오류 가능성을 줄이지만 모든 오류가 없음을 보증하지는 않습니다.

원본 문제집 대응은 생성 문항의 source에 기록합니다. curriculum.js의 기본 대응을 restoration.js에서 복원 유형별로 보완합니다. node scripts/review-gallery.mjs를 실행하면 로컬 review 폴더에 전체 113유형의 문장·그림·정답 대조본이 만들어집니다. 검토용 정답 페이지는 공개 배포하지 않습니다.

1단계 「옮겨 담기」는 생활 용기 11종의 990개 들이 조합을 사용합니다. 용기 짝을 번갈아 선택하며, 한 접속에서 전체 조합을 소진하기 전 같은 변형을 반복하지 않습니다. 새로고침하면 출제 순서는 다시 섞입니다. `node scripts/review-pouring.mjs`로 새 그림 검토본을 생성할 수 있습니다.
